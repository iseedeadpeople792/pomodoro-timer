# pomodoro-timer

Помодоро-таймер в браузере: 25 минут работы, 5 минут перерыва, каждый четвёртый перерыв длинный (15 минут). Без сборки и зависимостей, счётчик помидоров за день хранится в `localStorage`.

## Запуск
Из-за ES-модулей открывать нужно через локальный сервер:
```
python -m http.server 8000
```
и перейти на http://localhost:8000.

## Тест логики
```
node test.mjs
```

## Структура
- `timer.js` — логика (форматирование времени, смена фаз), покрыта тестом;
- `index.html` — интерфейс, светлая и тёмная тема.

Учебный проект для портфолио.
